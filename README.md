# SP
SP is a program made on the Java language to learn how to manage "big" batches of data,parsing,UI,and other aspects of programming using a prototype of a Spreadsheet Program,as the name implies.
## Run
Import it into eclipse,or run the compiled dot jar.
## Misc
Libraries that are used:
- Google's gson; for saving and loading the table.
- Swing; main UI library.

It is a simple project. Do not expect much.
